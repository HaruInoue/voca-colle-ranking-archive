# voca-colle-ranking-archive

ニコニコ動画の投稿イベント「ボカコレ（The VOCALOID Collection）」の
**毎時ランキングを記録し、順位の推移を後から見返せるようにする**非公式アーカイブ。

## なぜ作るのか

ボカコレの開催期間中、公式サイトでは 1 時間ごとに集計されたランキングが公開される。
しかし公開されるのは常に最新の 1 時点のみで、過去の時刻のランキングは参照できなくなる。
開催終了後は最終ランキングだけが残り、過去回のアーカイブも用意されていない。

結果として「どの曲がいつ伸びたか」「どこで順位が入れ替わったか」という
推移の情報が、半年ごとの開催のたびに失われている。それを残すためのプロジェクト。

## 構成

| ディレクトリ | 内容 |
|---|---|
| `collector/` | 公式サイトからランキングを取得して JSON として保存するスクリプト |
| `data/` | 収集したランキングデータ（開催回ごと） |
| `site/` | 収集したデータを閲覧する静的サイト（Astro） |
| `.github/workflows/` | 収集とデプロイの自動化 |

1. **収集**: GitHub Actions が開催期間中のみ 30 分間隔で起動し、
   その時間台を未取得の部門だけ公式サイトを取得する（正常時は 1 部門あたり毎時 1 リクエスト）。
2. **保存**: 集計時刻ごとのスナップショット JSON をこのリポジトリに蓄積する。
3. **閲覧**: Astro で静的サイトをビルドし、GitHub Pages に公開する。

## 出典と位置づけ

**本リポジトリは非公式のファンアーカイブであり、
ボカコレ運営およびニコニコ動画（株式会社ドワンゴ）とは一切関係がありません。**

- ランキング情報の出典は [ボカコレ公式サイト](https://vocaloid-collection.jp/)。
- 記録するのはランキングの順位と、公式サイトが公開している再生数・コメント数・
  マイリスト数・いいね数の実数、および楽曲の題名・投稿者名・投稿日時。
  **楽曲・サムネイル画像・音源は再配布しない**（サムネイルは公式 CDN の URL を参照するのみ）。

### 取得時の配慮

利用規約は過度な負荷を伴うアクセスを禁じている。次のように抑えている。

- **1 つの時刻・部門につき生涯 1 リクエスト。** 一度取得したら二度と取りに行かない。
  1 開催回あたりの総リクエスト数は約 210 回で、実行頻度を上げても増えない。
- 取得は直列で、1 リクエストごとに 1 秒あける。
- `User-Agent` にこのリポジトリの URL を入れ、何者からのアクセスかを明示している。

### 削除の依頼

公式・権利者の方からのご要望があれば速やかに対応します。
[Issue](https://github.com/HaruInoue/voca-colle-ranking-archive/issues) を立てるか、
リポジトリ所有者までご連絡ください。
